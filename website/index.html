what does the substep parameter actually control on a solver?
MorfyAI
Good question — rather than guess, I pulled the actual docs for that parameter. Substeps control how many sub-frames the solver simulates for every single frame, so raising it buys you accuracy at the cost of cook time, and vice versa. Here's a quick wrangle you could drop in to sanity-check the value before you raise it:
vex
// bail out if the solver is already substepping enough
int substeps = chi("../pyrosolver1/substeps");
if (substeps < 2) {
    warning("substeps may be too low for this scale");
}

Frequently asked

Questions people actually ask

No paid tiers, no hidden costs — just a plugin, your own API key, and a Houdini scene.

Is MorfyAI really free?

Yes — MIT licensed, no paid tiers, no locked features. A donation toward development is welcome but never required.

Is my API key and scene data safe?

MorfyAI talks directly to whichever provider you configure — Anthropic, OpenAI, or anything else you add. Nothing about your scene is routed through a third-party server we run.

Can I run it fully offline?

Yes — point it at a local model through Ollama and it works without an internet connection or a paid API key at all.

What's the difference between Auto and Plan mode?

Auto runs the whole task end-to-end on its own. Plan shows you every step first and waits for approval before touching a node. Both still give you per-operation Undo / Keep.

Does it work with third-party plugins like Axiom or MoPs?

Yes — curated recipes exist for Axiom, Paradigm, and MoPs, plus generic discovery for anything else installed in your scene.

Which Houdini version do I need?

Houdini 19.5 through 22 — including Houdini 22's Python 3.13 build. Drop the release into your packages/ folder and it appears next to your other packages automatically.
